# 外贸小程序课程免费开关

## 网页后台操作

网页入口：`https://waimao.englishecho.site/#/admin` → **运营设置 → 功能开关**。

2026-09-16 已部署并在线核验“小程序全课程免费”控件，位于交互总开关旁边。若仍看到旧页面，请刷新浏览器（必要时强制刷新）。后台保存 API 读写线上同一份小程序配置。

| 运营模式 | 小程序交互功能总开关 | 小程序全课程免费 |
| --- | --- | --- |
| 全部课程免费，保留音频 | 开 | 开 |
| 第一章免费，其余章节需会员 | 开 | 关 |
| 全部章节只读，无音频或会员入口 | 关 | 任意 |

修改开关后点击 **发布设置**，看到成功提示才算保存；“撤销修改”只撤销尚未发布的表单修改。刷新后台可检查保存结果，小程序重新打开/刷新课程后获取新配置。

“小程序解锁提示”仅在交互开启且免费关闭时实际显示；免费期间保留其设置和文案。以上课程权限开关只影响小程序，不改变外贸网页课程的收费规则，也不重写已有会员资格或有效期。

## 配置位置

生产服务器：`/www/wwwroot/englishpod/data/waimao-mini/app-config.json`。

不是同目录上一级的 `data/app-config.json`，后者属于 EnglishPod。自定义 `DATA_ROOT` 时使用 `$DATA_ROOT/waimao-mini/app-config.json`。

配置文件顶层添加/修改以下字段，保留其他配置：

```json
{
  "interactiveFeaturesEnabled": true,
  "allCoursesFree": true
}
```

- `allCoursesFree: true`：所有章节、小节正文、知识点和音频向所有人免费开放，包括未登录访客。
- `allCoursesFree: false`：恢复原收费方案，第一章免费，后六章要求有效会员。
- `interactiveFeaturesEnabled`：原有交互/音频总开关。正常免费运营保持 true；false 为全部章节只读、隐藏音频与会员的原有模式，不是本次免费运营开关。
- 新字段缺省为 false；必须使用 JSON 布尔值，不要写字符串 `"true"`。

## 生效与权益

后端每次请求读取配置，之后修改开关不需要重启或重新部署。小程序重新进入、刷新课程列表或下次读取配置时更新显示。无需逐个给用户开会员，也不会延长、清除或重写原有会员有效期。

免费期间兑换接口返回 `409 / all_courses_free`，不消耗邀请码。恢复收费后，未过期会员继续可用，其他用户回到第一章免费。

已下载内容无法撤回；之前签发的音频链接在自身有效期内仍可用，开关不是已发出内容的即时撤销机制。

## 已发布客户端兼容

- 后端将免费期的章节/小节 `free` 返回 true，使旧客户端也能打开全部课程；原试学资格放在 `trialFree`，不改课程源数据。
- 公开配置临时将 `home.unlockPromptEnabled` 返回 false；管理配置保留原值，恢复收费自动复用原文案。
- 新版客户端通过 `allCoursesFree` 独立隐藏会员入口、展示“全部课程免费开放”，音频和分享文案不受影响。
- 旧版“我的”等页面写死的会员标签需重新上传审核发布小程序才会完全消除；后端免费访问不以此次客户端发布为前提。

管理设置 API `GET/PUT /api/waimao/admin/settings` 读写同一份小程序配置。旧后台保存其他设置时若不传 `allCoursesFree`，服务端保留当前值。2026-09-16 后续已补齐网页管理控件；不改变网页版及 EnglishPod 的访问权限。

## 核验

读取 `GET /api/waimao-mini/app-config` 应看到两个开关均为 true；匿名读取 `GET /api/waimao-mini/courses` 应看到 7 章 50 节全部 `free: true`、`locked: false`；各小节详情应返回 200 和有效音频源。

恢复收费建议先在测试环境验证。生产直接修改为 false 会影响所有无会员用户的新请求。
