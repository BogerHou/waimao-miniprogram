# 磨耳朵

状态：2026-10-03 服务端听力接口及 Web 后台已部署；微信开发者工具实测一个七章专辑、首章播放进度超过一分钟、跨 Tab 小播放器及暂停正常。小程序源码未自动上传或发布，真机背景播放验收仍需单独完成。

## 产品边界

「磨耳朵」是轻量连续听力，不替代课程精练。目录按专辑组织；内置「外贸口语课程全集」复用七章整章音频。后续外贸对话、邮件表达等内容可单独建专辑。文本可选；听力时长与学习记录分开，目前仅保存本机断点和累计听力时长，不跨设备同步。

## 权限

- `interactiveFeaturesEnabled=false`：不允许听力起播或旧队列继续播放。
- `allCoursesFree=true`：全部已发布音频免费开放，不授予会员、不消耗邀请码。
- 收费模式：内置第一章免费，其余章节按课程会员权限；自定义专辑及曲目按后台设置。
- 草稿不出现在小程序中；停用、账号或权限变化后重新获取队列。

## 管理与协议

Web 后台「听力专辑」维护专辑、曲目、分类、顺序、发布状态、免费/会员和可选文本。新上传文件和新专辑默认草稿。保存使用版本号检测冲突，不覆盖另一位管理员的新修改。内置专辑和曲目的 ID/章节源不可删除或替换。

公开目录：`GET /api/waimao-mini/listening/albums`。播放队列：`GET /api/waimao-mini/listening/albums/:id/playback`，只返回已发布且当前有权播放的曲目及短期签名音源。管理目录：`GET/PUT /api/waimao/admin/listening/catalog`。音频上传：`POST /api/waimao/admin/listening/audio`，原始二进制及 `X-Audio-Filename`，最大 60 MB，支持 MP3/M4A/WAV。上传文件不放入公开静态目录；目录不返回文件路径或资产 ID。

## 播放与验收

全局后台播放器负责队列、断点、顺序/列表循环/单曲循环与定时关闭。退出听力页面不停止播放；其他 Tab 显示迷你播放器。进入课程播放或复习单词时暂停听力，避免叠音。签名 URL 不写入本地缓存，重新开始或权限变化时向服务端获取。

发布前必须在 iOS、Android 真机分别验证：锁屏连续跨曲、系统播放控制、蓝牙/耳机、微信退后台再返回、定时关闭、断网音源回退、播放中改变权限及原有精练/跟读衔接。开发者工具和模拟事件验证不能证明这些平台行为已通过。

开发版默认连接线上后端。此前听力页无内容是因为新目录接口尚未部署、返回 404；现已返回 200 和七章专辑。页面编译与服务接口是独立检查，原课程接口不依赖新听力服务。

## 后台操作

1. 后台进入「听力专辑」，点击「新建」，填写名称/分类/说明；免费或会员为该专辑的默认权限。
2. 上传音频，填写或确认时长，按需要填写原文。音频可覆盖专辑权限，或选择「跟随专辑」。上传完成不等于已发布。
3. 勾选专辑与音频的「上架」，调整顺序，点击「发布专辑目录」。只勾选不保存不会影响线上。
4. 下架取消相应勾选并再次发布。切换后台标签保留未保存草稿；刷新、重新读取前须确认放弃草稿。版本冲突保留本地修改，但需重新读取最新版本后再编辑。

内置专辑固定为七章；要添加其他音频，请新建专辑。第一章试用及原课程会员规则不可从此页面更改；统一在「运营设置」的「小程序全课程免费」调整。内容目录路径为 `$DATA_ROOT/waimao-mini/listening/catalog.json`，平时通过网页维护，不手改音频资源 ID。
