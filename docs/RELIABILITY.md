# 稳定性与可运维性

## 关键路径

以下音频关键路径在 `interactiveFeaturesEnabled=true` 时进入发布验收。会员链路另要求 `allCoursesFree=false`；免费模式应验证匿名访问全部课程且音频正常、无会员入口。交互关闭时，应验收全部章节可见可读、页面只读且不存在会员/播放入口或旧深链自动起播。配置与客户端发布边界见 [课程访问配置](COURSE_ACCESS.md)。

- 小程序首页能加载 `/api/waimao-mini/courses` 并展示 7 章。
- 匿名用户能进入第一章小节。
- 未解锁用户进入后 6 章小节时应看到锁定提示，完成头像/昵称登录后再跳转解锁页。
- 解锁页应展示添加微信二维码和会员权益，并允许登录用户输入会员邀请码解锁全部章节 1 年访问权。
- 登录用户能写入小节进度、学习时长和头像。
- 学习时长上报必须同时携带本次精练次数；学习主页从 `/api/waimao-mini/users/me/study-records` 刷新累计摘要，接口失败时不得清空本地用户摘要或复习资料，并在概览内提供重试入口。
- 小节完成时进度上报必须包含 cue 位置和总 cue 数，避免只保存粗粒度完成状态。
- 通听与跟读的连续播放必须停在当前小节 `range.end`，不能继续播放整章后续场景。
- 首页有历史课程树时必须先显示缓存再静默刷新；15 秒请求超时或断网后允许回退过期课程树，登录态进度和权益继续以本地 store 为准。
- 前台逐句与后台连续播放通道都必须在 CDN 加载 10 秒未就绪或收到错误时切到下一音源，并保留播放位置与 autoplay 意图；音源回退、音频加载超时和 API 5xx/网络失败应进入 `/api/waimao-mini/metrics` 结构化日志。观测失败不得阻断请求、播放或触发递归上报。
- 匿名用户长按课程单词时，`/api/waimao-mini/dictionary/:word` 应返回课程词典释义、英美音标和两个发音地址；缺词返回 404，非法输入返回 400，不得回退为每次调用 AI。

## 本地验证

小程序仓库：

```sh
npm run typecheck
npm test
npm run release:check
```

后端仓库：

```sh
npm run build
npm test
npm run waimao-mini:generate
npm run dev
```

或在小程序仓库运行：

```sh
npm run dev:backend
```

## 运行注意

- 磨耳朵上线前先发布后端和 Web 管理页，再上传小程序；现有 `release:check` 的线上检查覆盖既有课程，不证明新听力路由已部署。新模块的发布清单见 [LISTENING.md](LISTENING.md)。
- 听力恢复只存稳定 ID、位置、播放模式与本机时长；签名源留内存，临近到期或发生到期错误重新取队列。账号或课程权限变化停止当前队列并重新授权，不能恢复旧缓存源。服务端变更未推送到正在后台运行的客户端，需重新打开/请求才能获取新配置。
- 上传入口需在 Nginx 允许约 64 MB 请求体；服务端流式校验、背压写临时文件，失败清理。删除专辑条目不删除音频文件；第一版没有转码、存储配额、资源自动回收或音频云备份。

- `npm run waimao-mini:generate` 会从外贸 Web 数据源生成章节与课程详情，并从校验过 SHA256 的固定 ECDICT 版本生成课程专用词典；可用 `ECDICT_SOURCE_PATH` 指向已经下载的原始 CSV。
- 微信开发者工具、体验版和正式版默认都请求线上 `https://englishecho.site`；需要本地联调时再临时切换 `DEVELOPMENT_API_BASE_URL`。
- 发布验收必须开启合法域名校验；微信后台 `request` 需包含 `https://englishecho.site`，`downloadFile` 需包含 `https://englishecho.site`、`https://dict.youdao.com` 与 `https://waimao-audio.englishecho.site`。
- 已缓存登录态刷新失败时，只要持久化 token 仍存在就保留本地用户与权益；只有请求层确认 401 并清除 token 后才重新登录。
- 线上音频优先使用七牛私有签名地址（默认两小时，`QINIU_URL_TTL_SECONDS` 可配置 5 分钟至 24 小时），失败时自动切换约两小时有效的服务器签名源；进入课程会重新获取地址，不应持久化缓存。
- AI 讲解会在外贸知识点上下文存在时启用外贸沟通语境提示；普通 EnglishPod 接口不应受影响。
- 生词和难句第一期只保存在本机；清理小程序数据或更换设备会丢失，不能作为跨端真源。录音不保存、不上传。
- 登录和 401 重新认证必须保全 `waimao_review_library_v1` 与 `waimao_starred_cues_v1`；认证后只补回缺失 key，不覆盖登录期间的较新收藏。
- 复习页生词发音使用单一音频上下文；切换生词、Tab、删除当前生词或离开页面时停止当前音频，加载和播放错误只显示低打扰提示，不能残留错误播放态。
- 复习页回到精练来源句时，自动播放意图必须与 `cueId` 一起传递；课程音频未就绪时把目标句保存在 `pendingSubtitle`，由 `onCanplay` 走标准 `playSubtitle` 路径起播并设置句末停止，不能用固定延时猜测音频就绪时间。
- 中文查词不再依赖有道 JSON；按用户要求保留的英音/美音仍使用 `dict.youdao.com/dictvoice`，因此微信 `downloadFile` 合法域名暂时不能移除该域名。
- 课程生成前必须扫描 cue 与知识点 dialogue 的已知粘连/OCR 脏模式；词典生成必须达到真实课程词零缺失。邮箱、网址和产品型号属于结构化实体，不计入词典覆盖率；字幕分句必须保留邮箱和 URL 内部点号，只在结构化实体末尾的真实句号处分句。
- 通用 API 请求超时为 15 秒。metrics 在本地最多缓冲 50 条、默认 10 条或 30 秒 flush，退后台时主动 flush；服务端单批最多接收 10 条并按 IP 限流。
- 2026-07-13 已完成 `interactiveFeaturesEnabled=false` 的真机验收：7 章均可读，会员与音频文案和入口隐藏，重新登录后本机收藏保留。重新开启交互能力前需单独回归音频、录音、发音和邀请码链路。

## 已知短板

- 暂无小程序端真机自动化测试。
- 三类客户端异常已进入服务端结构化 stdout，但暂无可视化面板、告警阈值和多实例共享限流；仍需部署平台确认日志采集并补持续探测。也没有断点续播跨设备同步；商业化链路为添加微信购买邀请码，不接小程序支付。
- 学习记录接口已于 2026-07-12 部署并完成登录态联调；当前关闭态体验版已于 2026-07-13 完成真机核对。
