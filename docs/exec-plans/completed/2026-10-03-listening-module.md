# 磨耳朵专辑模块

## 目标

在小程序新增独立「磨耳朵」Tab，复用现有七章音频形成可连续播放的专辑，并允许管理员在 Web 后台维护其他外贸听力专辑。听力与精练进度隔离，沿用线上免费/会员和交互能力开关。

## 范围

- 包含：专辑/曲目接口与管理、私有音频上传、连续播放、断点续听、跨 Tab 迷你播放器、播放模式与定时关闭、音频互斥、回归测试和使用文档。
- 不包含：登录流程修改、付费方式重做、跨设备听力记录同步、自动部署或提交现有工作区变更。
- 涉及三个仓库：本仓库、`englishpod-server/server`、外贸 Web 项目。保留已有未提交改动。

## 风险与约束

- 微信后台音频能力和定时器受平台限制；模拟测试不能替代真机锁屏跨曲和定时关闭验收。
- 背景音频管理器全局唯一：共享音频焦点；课程/复习的旧事件回调不得接管听力。
- 签名 URL 只留内存；恢复和权限变化重新取播放队列，禁止持久化已授权 URL。
- 新音频私有存储、限制大小/格式；仅已发布且有权访问的曲目进入播放队列。
- 内置课程仍遵守第一章试用规则，不通过专辑设置绕过课程权限。

## 里程碑与验证

1. 固定数据协议与模块边界。
2. 并行实现小程序 UI、Web 管理、后端；主线程实现全局播放器及旧播放器衔接。
3. 三仓库类型检查、测试、构建；隔离本地后台交互验证。
4. 文档和 history 同步；明确未部署与待真机验证项。
